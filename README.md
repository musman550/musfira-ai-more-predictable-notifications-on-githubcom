## Overview

Starting December 1, 2026, GitHub is migrating all notifications on GitHub.com over the course of a week to make subscriptions more predictable, correct unexpected behavior, and support the growing scale of activity. This change is part of a broader effort to enhance the user experience and align with the platform's long-term vision.

As a developer or project manager, you might find that this transition affects your workflow. For example, you might notice that your notifications, which are currently triggered by events such as new commits or issues, may now trigger based on a more consistent schedule. This change aims to reduce the unpredictability of notifications and make your experience with GitHub more predictable and consistent.
